forma.

01

Jogo SnowMan

Jogo de puzzle desenvolvido em Java com JavaFX, inspirado em A Good Snowman Is Hard to Build. O jogador controla uma personagem, empurra e combina bolas de neve para construir um boneco de neve. Inclui dois níveis predefinidos, opções para desfazer e refazer movimentos e carregar níveis a partir de ficheiros.

Explora o Projeto no GitHub ↗
02

Guia do Sabor

Aplicação de gestão e consulta de receitas desenvolvida em Angular com a API TheMealDB. Inclui a visualização detalhada das receitas, filtros, pesquisa e uma API REST com funcionalidades para adicionar favoritos, criar receitas próprias, apagar receitas e editar receitas.

Ver repositório privado ↗
03

Run Tracker App

Aplicação móvel desenvolvida em Android Studio com Kotlin, que permite visualizar e inscrever-se em eventos fictícios, acompanhar uma meta diária de passos, monitorizar corridas, ganhar pontos e consultar as calorias gastas.

Ver repositório privado ↗
04

Jogo do Moinho

Implementação do jogo do Moinho em Python, jogável no terminal. Permite que um jogador enfrente o computador em três níveis de dificuldade, aplicando algoritmos minimax e validação das regras do jogo. O projeto inclui a colocação das peças, os movimentos entre casas adjacentes e a detecção de vitória.

Explora o Projeto no GitHub↗
05

Site de Cartas

Implementação de uma aplicação Django para recolher e consultar cartas Pokémon. Guarda informações como nome, tipo, vida, habilidade e fraqueza, e disponibiliza uma página web e uma API com os dados.
