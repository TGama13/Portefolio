01

Jogo SnowMan

Jogo de puzzle desenvolvido em Java com JavaFX, inspirado em A Good Snowman Is Hard to Build. O jogador controla uma personagem, empurra e combina bolas de neve para construir um boneco de neve. Inclui dois níveis predefinidos, opções para desfazer e refazer movimentos e carregar níveis a partir de ficheiros.

Explora o Projeto no GitHub ↗
02

Guia do Sabor

Aplicação de gestão e consulta de receitas desenvolvido em Angular com API de receitas The Meal DB tendo funcionalidade de ver detalhes de receitas, filtros e pesquisa e API REST com funcionalidades de favoritar, adicionar receitas próprias, apagar receitas e editar receitas.

Explora o Projeto no GitHub ↗
03

RPG Game

Jogo RPG desenvolvido em Java com JavaFX. Implementa atributos e progressão do jogador, incluindo níveis, experiência, vida, mana, força e ouro. Inclui um sistema de inventário com armas, armaduras e poções, equipar e desequipar equipamento, melhorias, reparações, durabilidade e recuperação de atributos.
O projeto ainda se encontra em desenvolvimento.
